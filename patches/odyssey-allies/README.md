# Odyssey Allies + Resourceful Lib

Self-hosted, not via `[update.modrinth]`. Neither project has published a
NeoForge build for 1.21.1 yet (latest builds target 1.21). These are the
1.21 jars, self-hosted so the pack doesn't depend on a Modrinth version
query that returns nothing for 1.21.1.

Replaces FTB Teams (party/ally system). Update manually when a 1.21.1
build ships: download from https://modrinth.com/project/odyssey-allies
and https://modrinth.com/mod/resourceful-lib, replace the jars here, and
update the hashes in `client/mods/odyssey-allies.pw.toml`,
`server/mods/odyssey-allies.pw.toml`, `client/mods/resourceful-lib.pw.toml`
and `server/mods/resourceful-lib.pw.toml`.

Current versions: Odyssey Allies 2.0.0, Resourceful Lib 3.0.12 (both for
NeoForge 1.21, 2026-10-28).

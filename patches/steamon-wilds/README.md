# Steamon Wilds

Gaspard's own mod: world content for the Steamon server (habitats,
spawns, loot, Mega Showdown placement). Also removes AE2's meteorite
worldgen itself, so the standalone `no-ae2-meteorites` patch was
dropped - keeping both would be redundant.

Self-hosted here because the GitHub repo is private, so a raw.githubusercontent.com
URL would not resolve for anyone else. Published on CurseForge
(project 1757744) but not on Modrinth, so no `[update.modrinth]`
section in the `.pw.toml`.

Update by downloading the new jar from the private repo's release and
replacing the file here, then updating `filename`/`url`/`hash` in
`client/mods/steamon-wilds.pw.toml` and `server/mods/steamon-wilds.pw.toml`.

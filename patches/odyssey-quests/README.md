# Resourceful Lib (Odyssey Quests dependency)

Self-hosted, not via `[update.modrinth]`. Resourceful Lib has no
NeoForge build for 1.21.1 yet (latest builds target 1.21). This is the
1.21 jar, self-hosted so the pack doesn't depend on a Modrinth version
query that returns nothing for 1.21.1. Required by Odyssey Quests.

Update manually when a 1.21.1 build ships: download from
https://modrinth.com/mod/resourceful-lib, replace the jar here, and
update the hash in `client/mods/resourceful-lib.pw.toml` and
`server/mods/resourceful-lib.pw.toml`.

Current version: 3.0.12 (NeoForge 1.21, 2026-10-28).

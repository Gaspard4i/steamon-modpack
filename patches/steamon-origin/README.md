# Steamon Origin

Gaspard's own mod (modId `steamon_ui`), the custom NeoOrigins addon for the
SMP's team/class system. Submitted to Modrinth and CurseForge and currently
awaiting review on both. Self-hosted here so the pack still builds and
installs correctly while the review is pending.

Requires the `neo-origins` mod (already added to the pack as its own
dependency).

Repo: https://github.com/Gaspard4i/Steamon-Origin (private).

Switch `.pw.toml`'s `[download]` back to a Modrinth/CurseForge reference
once the project is approved.

# Molten Vents Rarer

Self-hosted datapack. Overrides all 12 of Create: Molten Vents' placed
features (6 land vents + 6 aquatic vents) to spawn 10x more rarely, by
multiplying each `rarity_filter` chance by 10 (land: 1000 -> 10000,
aquatic: 690 -> 6900). Only the chance values changed, everything else
is identical to the mod's own files.

Update manually if Create: Molten Vents changes its placement logic or
default chances in a future version.

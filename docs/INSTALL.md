# Installation

## Client (joueur)

1. Installer [Modrinth App](https://modrinth.com/app)
2. Onglet "Modpacks" → chercher **Steamon** → installer la version `Client`
3. Lancer

Alternative : Prism Launcher, ATLauncher — tous supportent l'import `.mrpack`.

## Serveur dédié

1. Télécharger le `.mrpack` `Steamon Server` depuis https://modrinth.com/project/steamon
2. Le `.mrpack` est un ZIP — extraire son contenu dans un dossier de serveur
3. Installer NeoForge 1.21.1 (https://neoforged.net/)
4. Copier les `mods/`, `config/`, `datapacks/` extraits dans le dossier serveur
5. Lancer le serveur via le script `run.sh` / `run.bat` de NeoForge

Configuration recommandée : 8 Go RAM minimum, view-distance 8, simulation-distance 6.

## Mise à jour

Modrinth App détecte automatiquement les nouvelles versions et propose la mise à jour.

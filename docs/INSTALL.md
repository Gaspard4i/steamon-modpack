# Installation

## Client (player)

1. Install [Modrinth App](https://modrinth.com/app)
2. Modpacks tab → search **Steamon** → install the `Client` version
3. Launch

Alternative launchers: Prism Launcher, ATLauncher, MultiMC — they all support `.mrpack` imports.

## Dedicated server

1. Download the `Steamon Server` `.mrpack` from https://modrinth.com/project/steamon
2. The `.mrpack` is a ZIP — extract its contents into a fresh server directory
3. Install NeoForge 1.21.1 (https://neoforged.net/)
4. Copy the extracted `mods/`, `config/`, `datapacks/` into the server directory
5. Run the server with NeoForge's `run.sh` / `run.bat`

Recommended configuration: 8 GB RAM minimum, view-distance 8, simulation-distance 6.

## Updates

Modrinth App automatically detects new versions and offers to update.
